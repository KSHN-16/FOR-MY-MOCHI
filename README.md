## Adding your background music

For copyright and personalization reasons, the website is prepared for your own audio file.

1. Choose a soft romantic instrumental MP3 that you have permission to use.
2. Rename it to `music.mp3`.
3. Place it in the same folder as `index.html`.
4. Open the website.

The music will start after the first interaction, which is required by most browsers.

## Running the website

Open `index.html` in a browser.
